03 - WHY

Built for the boring part

Free endpoints are actually free

The deterministic side is pure code on the edge: no model, no tokens, no per-call cost. Run your keywords and entities extraction over a whole archive.

Neural where it earns its keep

Summaries, rewrites, zero-shot labels and translation go through Workers AI with tight max_tokens caps, so latency stays in the seconds and cost stays predictable.

Same response shape

Every endpoint returns a meta block with costClass free or neural, model id and duration, so you can route traffic and forecast spend.

06 - FAQ

Questions we get asked

Which endpoints cost nothing?

keywords, entities, sentiment, detect-language and readability are deterministic code. They are marked costClass free in every response.

What happens if the AI model is unavailable?

You get a 503 with code AI_UNAVAILABLE and a retry hint. The free endpoints keep working, so your product degrades instead of breaking.

Can I choose the model?

A default is pinned per endpoint. Ask for a specific model and it can be wired into your plan.

Is my text stored?

No. Text is processed in memory inside the request and discarded.
