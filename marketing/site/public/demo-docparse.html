Live demo / DocParse

Paste a link, get the text back

Point it at a PDF or an HTML page. The API detects which is which, fetches it, and returns the readable text with counts. Try a paper, a help page, an invoice.

Sends one live request to docparse.ayamk.in/v1/pdf/text or /v1/html/text.

01 - WHAT YOU ARE SEEING

The same call handles three formats

detection

A .pdf path goes to the PDF parser, anything else to the HTML reader. You do not branch.

counts

characters, words and page count, so you can budget chunking before you pay for embedding.

no storage

The file lives in memory for the request only. Nothing is written to a bucket.

no OCR

A scanned PDF has no text layer and comes back empty. That is a different service, stated plainly.

Ten demo calls per visitor per day. Past that the endpoint returns 429 and points at the listing, because a demo that never ends is a free tier.
