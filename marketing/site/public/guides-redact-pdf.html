Redact PII from a PDF in two calls

A PDF is a container, not text. You cannot redact what you have not extracted, so the job splits cleanly: one call turns the file into text, the next finds and masks the personal data. Here is the working flow and where it stops.

The two steps

1. DocParse pulls the text out of the PDF, page by page, and gives you metadata alongside it. 2. PII Shield scans that text and returns every finding with an offset, a type and a confidence score, or the redacted version directly.

// 1. PDF to text
const extracted = await fetch('https://docparse.p.rapidapi.com/v1/pdf/text', {
  method: 'POST',
  headers: {
    'content-type': 'application/json',
    'x-rapidapi-key': process.env.RAPIDAPI_KEY,
    'x-rapidapi-host': 'docparse.p.rapidapi.com',
  },
  body: JSON.stringify({ url: 'https://example.com/contract.pdf' }),
}).then((r) => r.json());

// text is the joined document, pages is one string per page
const text = extracted.pages.join('\n\n');

// 2. find the personal data
const scanned = await fetch('https://piishield.p.rapidapi.com/v1/scan', {
  method: 'POST',
  headers: {
    'content-type': 'application/json',
    'x-rapidapi-key': process.env.RAPIDAPI_KEY,
    'x-rapidapi-host': 'piishield.p.rapidapi.com',
  },
  body: JSON.stringify({ text }),
}).then((r) => r.json());

console.log(scanned.findings.map((f) => f.type + ' at ' + f.start));

If you want the redacted text, not the list

Call /v1/redact instead of /v1/scan on the extracted text. Choose a style based on what happens next:

  • label keeps entities consistent, so the same person stays [EMAIL_1] throughout the document.
  • mask keeps the last four characters, which is what a human reviewer usually needs.
  • hash lets you join documents later without storing the value.

Where this stops, honestly

Scanned PDFs. If the page is an image, there is no text layer and nothing to redact. DocParse does not OCR and does not pretend to; you get a clear signal rather than an empty result.

Redaction is not a black box. The output here is text with placeholders. If you need a pixel-level redaction burned into the PDF, that is a different operation and this flow does not do it.

Table layout is lost. Extraction returns reading order, not a grid, so per-cell redaction needs your own parsing on top.
