EmailCheck API reference

Validate email addresses before you send, store or bill for them.

Every call runs a syntax pass, live DNS lookups (MX + A/AAAA), a 10,000+ domain disposable-mailbox blocklist, role-account detection, free-provider detection, typo suggestions and a 0-100 deliverability score with human readable reasons.

Honest scope: no SMTP handshake happens at the edge, so the API tells you whether the domain accepts mail and how risky the address looks. It does not claim to prove that a specific mailbox exists. Results are cached at the edge for 10 minutes to keep latency low.

Built for: signup forms, lead qualification, CRM hygiene, bulk list cleaning, fraud checks.

Auth

Two headers on every call. The marketplace rejects requests without them before they reach the API.

X-RapidAPI-Key: YOUR_KEY
X-RapidAPI-Host: emailcheck.p.rapidapi.com

Errors

Every failure returns the same envelope, with a requestId you can quote to support.

{ "error": { "code": "INVALID_INPUT", "message": "...", "hint": "..." }, "requestId": "uuid", "timestamp": "ISO-8601" }

5 endpoints

GET /v1/verify

Verify a single email address

Runs the full pipeline for one address: syntax, MX/AAAA DNS, disposable blocklist, role account detection, free provider detection, typo suggestion and scoring.

ParameterInTypeDescription
emailquerystring (required)Address to verify.
curl example 
curl -s -X GET 'https://emailcheck.ayamk.in/v1/verify' \
  -H 'X-RapidAPI-Key: YOUR_KEY' \
  -H 'X-RapidAPI-Host: emailcheck.p.rapidapi.com'
POST /v1/verify

Verify a single email address (JSON body)

Same pipeline as the GET variant. Useful when addresses contain characters that need escaping in a query string.

Request body

{
  "email": "jane@example.com"
}
curl example 
curl -s -X POST 'https://emailcheck.ayamk.in/v1/verify' \
  -H 'X-RapidAPI-Key: YOUR_KEY' \
  -H 'X-RapidAPI-Host: emailcheck.p.rapidapi.com' \
  -H 'Content-Type: application/json' \
  -d '{"email": "jane@example.com"}'
POST /v1/bulk

Verify up to 100 addresses in one request

Deduplicates the input by canonical form, verifies with bounded concurrency and returns per-address results plus an aggregate summary. Regex-free: invalid lines are reported, not rejected.

Request body

{
  "emails": [
    "jane@gmail.com",
    "info@stripe.com"
  ]
}
curl example 
curl -s -X POST 'https://emailcheck.ayamk.in/v1/bulk' \
  -H 'X-RapidAPI-Key: YOUR_KEY' \
  -H 'X-RapidAPI-Host: emailcheck.p.rapidapi.com' \
  -H 'Content-Type: application/json' \
  -d '{"emails": ["jane@gmail.com", "info@stripe.com"]}'
