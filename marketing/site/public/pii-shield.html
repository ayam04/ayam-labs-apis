03 - WHY

Built for the boring part

Validators, not just regex

A 16 digit number is not a card unless it passes Luhn. An IBAN is not an IBAN unless mod-97 checks out. That difference is the difference between a useful signal and noise.

Spans you can trust

Overlapping matches are resolved deterministically: the more specific, higher confidence detector wins. Findings come back sorted with start and end offsets, ready for highlight UIs.

Zero egress

Regex, checksums and wordlists inside the Worker. Your text never leaves the request, which is the only version of this a compliance team will sign off.

06 - FAQ

Questions we get asked

Is this a substitute for a DLP product?

No. It is a fast pre-filter: catch the obvious PII in text before it lands somewhere permanent. Pair it with policy and access control, not instead of them.

Can I reverse a redaction?

With style hash you get a stable 8 character digest per value, so you can correlate occurrences without storing the original. Masks and labels are not reversible.

Which languages are supported for profanity?

English is the most complete list. Spanish, French and German cover common terms. The PII detectors are language independent.

How fast is it?

Deterministic scans on 10KB of text return in single digit milliseconds. The response includes durationMs so you can measure it yourself.
