01 - WHAT YOU ARE SEEING

Every check carries a weight and a message

score.value

0 to 100, computed from fourteen weighted checks. Not a vibe, arithmetic.

status

pass, warn or fail, with the points awarded so you can see what a fix is worth.

message

Plain English, e.g. "Title is 14 characters; aim for 15-60."

timings

fetch and parse milliseconds, so you know whether the site or the parser was slow.

Ten demo calls per visitor per day. Past that the endpoint returns 429 and points at the listing, because a demo that never ends is a free tier.
