## What this does

Six text functions behind one key, running on Cloudflare Workers AI at the edge, with no prompt engineering required from you.

Send text, get structure back: sentiment with confidence, keywords with weights, entities with types, a language code, a summary at the length you ask for, or a rewritten version in the tone you specify.

## Endpoints

- **POST /v1/sentiment** - positive, negative, neutral or mixed, with a score
- **POST /v1/keywords** - ranked keywords and phrases, stop words removed
- **POST /v1/entities** - people, organisations, places, dates, amounts
- **POST /v1/detect-language** - language code and confidence
- **POST /v1/summarize** - summary at a target length
- **POST /v1/rewrite** - same meaning, different tone or reading level
- **POST /v1/classify** - zero-shot classification into your own labels
- **POST /v1/readability** - Flesch, Flesch-Kincaid, Gunning fog
- **POST /v1/translate** - between 100 languages
- **GET /v1/stopwords** - the stop word list used by the keyword endpoint

## What to expect

The deterministic endpoints (sentiment, keywords, entities, readability, language) do their work in single-digit milliseconds server side; a measured client round trip was 152ms p50. The neural ones (summarize, rewrite, classify, translate) take 1-3 seconds, 2.4s p50 measured.

## Limits, stated plainly

Summaries and rewrites are generated by a 20B model and can occasionally miss nuance on very technical text. The API returns what the model produced rather than smoothing it over, so you can post-process or retry. Text is not stored.
